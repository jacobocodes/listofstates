# State Checklist

A single-page web app for tracking which states you have.

- Check off the states you have; the app shows how many you have and don't have, with cost totals.
- Filter to **Have** / **Don't have**, search, and copy a list of the states you still need.
- **Cost calculator** tab: tick any states to see what they would cost together, without changing your checklist.
- **Settings** lets you edit the list (names, costs, notes), then share a blank copy by link or as plain text. Opening the link gives the recipient their own copy with nothing checked.

Everything is saved in your browser (localStorage). No server needed: open `index.html` directly, or host it with GitHub Pages. To share a blank copy, use the share link (hosted version) or "Copy blank list as text".
